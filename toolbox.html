一、描述統計與標準化

1.1 集中趨勢

算術平均數

$$\bar{x} = \frac{\sum_{i=1}^{N} X_i}{N} = \frac{\sum X}{N}$$
把所有數字加起來（$\sum X$ 是「全部相加」），再除以總個數 $N$。$\bar{x}$ 唸作「x bar」，代表平均。
中位數 (Md)排序後第 $\frac{N+1}{2}$ 個值；偶數 $N$ 取中間兩值平均
眾數 (Mo)出現次數最多的值（可有多個）
偏態與三者正偏（右偏）：$\text{Mo} < \text{Md} < \bar{X}$　　負偏（左偏）：$\bar{X} < \text{Md} < \text{Mo}$
偏態方向看「尾巴拖到哪邊」：正偏＝尾巴拖右邊（少數高分把平均拉高 → 平均最大）；負偏＝尾巴拖左邊（少數低分把平均拉低 → 平均最小）。記憶法：平均跟著尾巴跑。

1.2 離散趨勢

母群變異數（定義式）

$$\sigma^2 = \frac{\sum(X_i - \mu)^2}{N}$$
$\sigma$ 唸「sigma」、$\mu$ 唸「mu」（母群平均）。每筆資料減去平均 → 平方（避免正負抵消）→ 全部加起來 → 除以 $N$。意義：平均來說，每筆資料離平均「平方距離」是多少。

母群變異數（計算式）

$$\sigma^2 = \frac{\sum X_i^2 }{N}- \mu^2 = \frac{\displaystyle\sum X^2 - \frac{(\sum X)^2}{N}}{N}$$
這是速算版，不必先算每個離差，直接用 $\sum X^2$（每個數字平方後加總）和 $\sum X$（直接加總）就能算。考試手算比較快。

樣本變異數（不偏，定義式）

$$s^2 = \frac{\sum(X_i - \bar{x})^2}{N-1}$$
分母用 $N-1$（不是 $N$）才能不偏估計母群變異數。$N-1$ 叫「自由度」——因為平均已經用掉一個資訊。

樣本變異數（計算式）— 除 $N-1$

$$s^2 = \frac{\displaystyle\sum X^2 - \frac{(\sum X)^2}{N}}{N-1}$$
同上，速算版，分母換成 $N-1$ 就是樣本變異數。

標準差　　　變異係數

$$\sigma = \sqrt{\sigma^2},\quad s = \sqrt{s^2} \qquad CV = \frac{SD}{Mean} \times 100\%$$
標準差＝變異數開根號，把單位變回原本（變異數的單位是平方）。變異係數 CV＝標準差佔平均的百分比，用來比較不同單位/不同量級資料的離散程度（例：身高 vs 體重）。
全距$R = X_{\max} - X_{\min}$
四分位距$\text{IQR} = Q_3 - Q_1$
全距＝最大值減最小值（容易被極端值影響）；四分位距 IQR＝第 75 百分位 $-$ 第 25 百分位（中間 50% 的範圍，抗極端值）。
線性轉換：$\text{Var}(a+bX) = b^2\cdot\text{Var}(X)$；$\text{SD}(a+bX) = |b|\cdot\text{SD}(X)$；加常數 $a$ 不影響 SD
資料整體 $+a$（每筆加同一個數）→ 離散度不變（大家一起平移）。資料 $\times b$（每筆乘 $b$）→ 標準差變 $|b|$ 倍、變異數變 $b^2$ 倍。

1.3 z 分數（標準化）

z 分數　　　反推原始分數

$$z = \frac{X - \mu}{\sigma} \qquad X = \mu + z\cdot\sigma$$
z 分數的意思：「我距離平均有幾個標準差」。$z=+2$ 代表比平均高 2 個標準差；$z=-1$ 代表比平均低 1 個標準差。右式是反推：知道 $z$ 倒回去算原始分數。
標準化後：$\mu_z = 0$，$\sigma_z = 1$（分配形狀不變！）
把整批資料都做 z 轉換後，新平均一定是 0、新標準差一定是 1，但分配形狀（偏態、峰度）完全沒變。
z 轉換不改變分配形狀！原始非常態 → 轉換後仍非常態

1.4 偏態與峰度

偏態（Skewness）—— 三次方矩

$$g_1 = \frac{\dfrac{1}{N}\sum(X_i - \bar{x})^3}{s^3}$$
用三次方是因為要保留正負號（左偏為負、右偏為正）。$g_1 = 0$ 對稱；$g_1 > 0$ 右偏（尾巴拖右）；$g_1 < 0$ 左偏（尾巴拖左）。

峰度（Kurtosis）—— 四次方矩（尾端厚度）

$$g_2 = \frac{\dfrac{1}{N}\sum(X_i - \bar{x})^4}{s^4} - 3 \quad\text{（超額峰度；常態分配 }g_2=0\text{）}$$
四次方放大「離平均很遠的點」的影響，所以衡量尾巴厚不厚。減 3 是因為常態分配的原始峰度=3，減掉後常態的「超額峰度」=0 比較好對照。$g_2 > 0$ 尾巴厚（極端值多）；$g_2 < 0$ 尾巴薄。

二、機率分配

2.1 常用分配摘要

常態 $N(\mu,\sigma^2)$$\mu\pm1\sigma=68.26\%$；$\mu\pm2\sigma=95.44\%$；$\mu\pm3\sigma=99.74\%$
標準常態 $Z$$\mu=0$，$\sigma=1$；$z_{0.025}=1.96$，$z_{0.005}=2.576$
$t(df)$$df\to\infty$ 趨近 $Z$；$\text{Var}=\dfrac{df}{df-2}>1$，尾端比 $Z$ 厚
$\chi^2(df)$$\chi^2=\sum Z_i^2$（$df$ 個獨立 $Z^2$ 之和）；右偏；$df\to\infty$ 趨近常態
$F(df_1,df_2)$$F=\dfrac{\chi^2(df_1)/df_1}{\chi^2(df_2)/df_2}$；右偏；$F=t^2$（兩組）
二項 $B(n,p)$$E(X)=np$；$\text{Var}=np(1-p)$；$n$ 大時趨近常態
波松 $\text{Pois}(\lambda)$$E(X)=\text{Var}(X)=\lambda$；單位時間事件次數
超幾何不放回抽樣；有限母群；每次 $p$ 改變
伯努利 $B(p)$$n=1$ 的二項；單次試驗（0或1）
常態就是鐘形曲線，68-95-99.7 法則：離平均 1/2/3 個 SD 內大約佔 68%/95%/99.7% 的資料。
$t$ 分配：樣本小、$\sigma$ 未知時用，長得像常態但尾巴比較厚（因為要多一份不確定性）；$df$ 越大越接近常態。
$\chi^2$ 分配：好幾個 $Z^2$（標準常態平方）加起來，因為是平方所以恆正、右偏。
$F$ 分配：兩個變異數（標準化後）的比值，恆正、右偏；ANOVA 用它。
二項：$n$ 次獨立試驗，每次成功機率 $p$，數成功幾次（如丟銅板 10 次幾次正面）。$E(X)=np$ 直觀：「次數 × 成功率」。
波松：單位時間/空間內事件發生次數（如每小時來幾通電話）；平均=變異數=$\lambda$。
超幾何：抽不放回（如抽撲克牌不放回），每抽一張機率就變了。
伯努利：只做一次試驗（成功=1 / 失敗=0）；是二項的特例 $n=1$。
$F=t^2$（兩組）；機率密度（PDF值）可以 $>1$（面積$=1$，高度不限）

2.2 抽樣分配與標準誤

標準誤（SE）

$$SE_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$$
標準誤就是「樣本平均的標準差」。同一個母群抽很多次樣本，每次算的 $\bar{x}$ 都會略有不同——這些 $\bar{x}$ 的分散程度就是 SE。樣本越大（$n$ 越大），SE 越小，估得越準（除以 $\sqrt{n}$）。

比例的 SE　　　兩比例差的 SE

$$SE_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}} \qquad SE_{\hat{p}_1-\hat{p}_2} = \sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}}$$
左式：當資料是 0/1（如支持/不支持），樣本比例 $\hat{p}$ 的標準誤。右式：兩組比例差的標準誤——把兩組 SE 平方相加再開根（因為兩組獨立，變異數可以相加）。

三、信賴區間與樣本數估計

均值 CI（$\sigma$ 已知）　　均值 CI（$\sigma$ 未知）

$$\bar{x} \pm z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}} \qquad \bar{x} \pm t_{\alpha/2,\,n-1}\cdot\frac{s}{\sqrt{n}}$$
結構都是「樣本平均 ± 臨界值 × 標準誤」。$\sigma$ 已知用 $z$，$\sigma$ 未知（要用樣本 $s$ 估）改用 $t$（尾巴比較厚以反映多出來的不確定性）。「95% CI」的意思是「同樣方法重複抽樣很多次，95% 算出的區間會包含真值」，不是「真值有 95% 機率落在這個區間」。

比例 CI

$$\hat{p} \pm z_{\alpha/2}\cdot\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$
同樣是「點估計 ± 臨界值 × 標準誤」，只是把均值換成比例。

樣本數估計（一般式）　　樣本數估計（保守，$p=0.5$）

$$n \geq \frac{z_{\alpha/2}^2\cdot p(1-p)}{E^2} \qquad n \geq \frac{z_{\alpha/2}^2\cdot 0.25}{E^2} = \left(\frac{z_{\alpha/2}}{2E}\right)^2$$
想讓誤差不超過 $E$，至少要抽多少人。$p$ 不知道時用 $p=0.5$（最保守，因為 $p(1-p)$ 在 0.5 達到最大 0.25）。$E$ 越小（要更精準）→ $n$ 越大，且 $E$ 在分母平方，所以「誤差減半 → 樣本要 4 倍」。

範例：95% 信心（$z=1.96$），誤差半寬 $E=0.02$

$$n \geq \left(\frac{1.96}{2\times 0.02}\right)^2 = 49^2 = 2401 \approx 2500$$
$E$ = 誤差「半寬」；若題目說「上下誤差總範圍 $0.04$」則 $E = 0.02$

四、假設檢定

4.1 基本概念

Type I error ($\alpha$)H$_0$ 為真卻拒絕 H$_0$（偽陽性）= 顯著水準
Type II error ($\beta$)H$_1$ 為真卻保留 H$_0$（偽陰性）
Power（統計力）$1-\beta = P(\text{拒絕 H}_0 \mid \text{H}_1\text{ 為真})$；通常要求 $\geq 0.80$
$p$ 值H$_0$ 為真時，觀察到此結果或更極端的機率
決策$p < \alpha \Rightarrow$ 拒絕 H$_0$；$p \geq \alpha \Rightarrow$ 保留 H$_0$（非接受！）
用「醫學檢驗」來想很好記：H$_0$＝「沒病」，H$_1$＝「有病」。
Type I（$\alpha$）= 偽陽性：沒病卻說有病（冤枉好人）。
Type II（$\beta$）= 偽陰性：有病卻說沒病（漏掉壞人）。
Power（$1-\beta$）＝「真有效時能正確抓到的機率」，是檢定的「靈敏度」。
$p$ 值＝「假如 H$_0$ 是真的，看到目前資料（或更極端）的機率」。$p$ 小代表資料和 H$_0$ 不合 → 拒絕 H$_0$。
注意「保留 H$_0$」不等於「H$_0$ 為真」，只是「沒有足夠證據反駁它」。
$\alpha + \beta \neq 1$！　Power $= 1-\beta$（不是 $1-\alpha$）
$\alpha\uparrow\Rightarrow$ Power $\uparrow$；$n\uparrow\Rightarrow$ Power $\uparrow$；效果量 $\uparrow\Rightarrow$ Power $\uparrow$

4.2 各種 $t$ 檢定

單樣本 $t$

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}},\quad df = n-1$$
「樣本平均離假設值差幾個標準誤」。$\mu_0$ 是 H$_0$ 設的目標值（如「平均身高=170」）。分子＝差距，分母＝標準誤。$|t|$ 越大代表離假設值越遠，越可能拒絕 H$_0$。

獨立樣本 $t$

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_p^2\!\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}},\quad df = n_1+n_2-2$$
「兩組平均的差距，等於幾個標準誤」。比較兩個獨立群體（如男女、實驗組對照組）。分母用「合併變異數」估兩組共同的變異程度。

調和變異數（Pooled Variance）

$$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$$
把兩組變異數用各自自由度當權重加總平均。前提是「兩組變異數相等」（同質性假設）。如果兩組 $n$ 差很多，大樣本那組的 $s^2$ 會占主導。

配對樣本 $t$　（$D_i = X_{1i} - X_{2i}$）

$$t = \frac{\bar{D}}{s_D/\sqrt{n}},\quad df = n-1$$
「同一個人前後測」或「配對的兩筆資料」。先算出每對的差 $D_i$，問題就變成單樣本：「平均差距 $\bar{D}$ 和 0 差幾個標準誤？」配對能消掉個體差異，檢定力比獨立樣本高。

$t$ 與 $F$ 的關係

$$F(1,\;df) = t^2(df)\quad\text{（兩組時）}$$
兩組比較時，做獨立樣本 $t$ 檢定 = 做單因子兩水準 ANOVA，且$F$ 值剛好是 $t$ 值的平方。$p$ 值也會完全一樣。

4.3 卡方檢定

卡方統計量　　　期望值（列聯表）

$$\chi^2 = \sum\frac{(O-E)^2}{E} \qquad E_{ij} = \frac{\text{列和}_i \times \text{欄和}_j}{N}$$
核心想法：「觀察值（$O$）和期望值（$E$）差多少？」$O-E$ 是差距、平方避免正負抵消、再除以 $E$ 做標準化（讓格子大小可比）。$\chi^2$ 越大代表差距越大，越可能拒絕「兩變項獨立」的 H$_0$。
期望值 $E_{ij}$＝「如果兩變項真的獨立，這格應該有多少」（用邊際機率算）。

適合度：$df = k-1$（$k$=類別數）　　獨立性：$df = (r-1)(c-1)$

適合度檢定：一個變項的分配是否符合理論比例（如骰子是否公平）。
獨立性檢定：兩個類別變項是否相關（如性別 × 投票偏好）。

單樣本變異數

$$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2},\quad df = n-1$$
檢定「樣本變異數和某個假設值 $\sigma_0^2$ 是否相同」。當 H$_0$ 為真時 $s^2 \approx \sigma_0^2$，這個比值會接近 $n-1$（即 $df$）。
期望值要求 $E \geq 5$（不是10！）；$E < 5$ 時考慮 Fisher's Exact Test

五、相關與迴歸

5.1 Pearson 相關

定義式

$$r = \frac{\text{Cov}(X,Y)}{\sigma_X\cdot\sigma_Y} = \frac{\sum(X_i-\bar{x})(Y_i-\bar{y})}{\sqrt{\sum(X_i-\bar{x})^2\cdot\sum(Y_i-\bar{y})^2}}$$
$r$ 是「共變數除以兩個標準差」 → 把單位消掉的相關，永遠落在 $-1$ 到 $+1$。
分子 $(X-\bar{x})(Y-\bar{y})$：當 $X,Y$ 同時大於或同時小於各自平均時為正（正相關）；一高一低時為負（負相關）。整批資料加總後，正相關會以正值居多。

計算式

$$r = \frac{\displaystyle\sum X_i Y_i - \frac{(\sum X_i)(\sum Y_i)}{N}}{\sqrt{\left[\displaystyle\sum X_i^2 - \frac{(\sum X_i)^2}{N}\right]\!\left[\displaystyle\sum Y_i^2 - \frac{(\sum Y_i)^2}{N}\right]}}$$
速算版：考試只要算 $\sum X$, $\sum Y$, $\sum XY$, $\sum X^2$, $\sum Y^2$ 五個量，直接代入即可。

共變數　　　$r$ 的 $t$ 檢定

$$\text{Cov}(X,Y)=r\cdot\sigma_X\cdot\sigma_Y \qquad t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}},\quad df=n-2$$
共變數：未標準化的相關，受單位影響大；除以兩個 SD 後就變成 $r$。
$r$ 的 $t$ 檢定：問「樣本算出的 $r$ 和 0 的差距，是否大到不能用抽樣誤差解釋」。$|r|$ 大、$n$ 大 → $t$ 大 → 越顯著。

決定係數

$$R^2 = r^2\quad\text{（$X$ 能解釋 $Y$ 的變異比例）}$$
$r=0.6$ 不代表「解釋 60% 的變異」，要平方：$R^2 = 0.36$，「$X$ 解釋了 $Y$ 中 36% 的變異」。
$r=0$ 只代表無「線性」相關；可能有非線性關係！
$R^2$ 對稱：$X$ 預測 $Y$ 和 $Y$ 預測 $X$ 的 $R^2$ 完全相同

5.2 簡單線性迴歸

迴歸方程式

$$\hat{Y} = b_0 + b_1 X$$
$\hat{Y}$ 唸「Y hat」＝預測值。$b_0$ 是截距、$b_1$ 是斜率；用 $X$ 來預測 $Y$ 的最佳直線。「最佳」的標準＝讓殘差平方和最小（最小平方法 OLS）。

斜率（定義式 / 計算式）

$$b_1 = \frac{\text{Cov}(X,Y)}{\text{Var}(X)} = r\cdot\frac{s_Y}{s_X} = \frac{\displaystyle\sum X_i Y_i - \frac{(\sum X_i)(\sum Y_i)}{N}}{\displaystyle\sum X_i^2 - \frac{(\sum X_i)^2}{N}}$$
斜率 $b_1$ 的意義：「$X$ 每增加 1 單位，$Y$ 平均變化多少」。中間式 $b_1 = r\cdot\frac{s_Y}{s_X}$ 很實用——已知 $r$ 和兩變項 SD 就能直接算斜率。

截距　　　標準化迴歸係數

$$b_0 = \bar{Y} - b_1\bar{X}\quad\text{（迴歸線必過 $(\bar{X},\bar{Y})$）} \qquad \beta = r\quad\text{（截距}=0\text{）}$$
截距 $b_0$＝「$X=0$ 時 $Y$ 的預測值」。迴歸線一定通過資料中心 $(\bar{X},\bar{Y})$。
標準化迴歸係數 $\beta$＝把 $X,Y$ 都做 z 轉換後再做迴歸的斜率，單變項時直接等於 $r$，截距為 0。

估計標準誤（SEE）

$$SEE = s_Y\sqrt{1-R^2} = \sqrt{\frac{\sum(Y_i-\hat{Y}_i)^2}{N-2}}$$
SEE 是「預測誤差的標準差」 → 預測值平均偏離真實值多少。$R^2$ 越大（解釋越多）→ SEE 越小（預測越準）。分母 $N-2$ 是因為估了截距和斜率兩個參數。

95% 預測區間　　　整體 $F$ 檢定

$$\hat{Y}\pm 1.96\cdot SEE \qquad F=\frac{R^2/p}{(1-R^2)/(N-p-1)},\quad df_1=p,\;df_2=N-p-1$$
預測區間：對某個特定 $X$ 值，$Y$ 大約落在 $\hat{Y} \pm 1.96\cdot SEE$ 內（粗略式）。
整體 $F$ 檢定：問「整個迴歸模型是否顯著」（$R^2$ 是否大到不能用抽樣誤差解釋）。$p$ 是預測變項數，這裡 $p=1$。
$X$ 和 $Y$ 互換後斜率不同（除非 $s_X=s_Y$），但 $R^2$ 相同

5.3 多元迴歸

多元迴歸方程式　　　調整後 $R^2$

$$\hat{Y} = b_0 + b_1X_1 + \cdots + b_pX_p \qquad R^2_{\text{adj}} = 1-(1-R^2)\frac{N-1}{N-p-1}$$
多元迴歸：用多個 $X$ 變項一起預測 $Y$。每個 $b_i$＝「控制其他變項不變時，$X_i$ 增加 1 單位，$Y$ 平均變化多少」。
調整後 $R^2$：$R^2$ 會隨變項越多而越大（即使加沒用的變項），調整後 $R^2$ 會懲罰多餘的變項，用來做模型比較才公平。

整體 $F$ 檢定

$$F(p,\;N-p-1)=\frac{R^2/p}{(1-R^2)/(N-p-1)}$$
問「至少有一個 $b_i \neq 0$」嗎？$F$ 顯著表示整個模型有效，但不告訴你哪個變項顯著（要看每個 $b_i$ 的個別 $t$ 檢定）。

5.4 虛擬變項與調節迴歸

$k$ 類別 $\Rightarrow$ $k-1$ 個虛擬變項（以1組為參照組）
截距 $=$ 參照組均值；各組係數 $=$ 該組均值 $-$ 參照組均值
虛擬變項（dummy）：把類別變項（如「血型 A/B/O/AB」4 類）變成 0/1 變數放進迴歸。$k$ 類只需 $k-1$ 個 dummy（多了會共線性），沒被編碼的那組叫「參照組」。每個 dummy 的係數＝「該組平均比參照組高/低多少」。
例：性別只要 1 個 dummy（女=0、男=1），$b_1$ 就是「男生比女生平均多多少」。

調節迴歸（含交互作用）

$$\hat{Y} = b_0 + b_1X + b_2Z + b_3XZ$$
$XZ$ 是 $X$ 和 $Z$ 相乘的「交互作用項」。$b_3$ 顯著代表 $X$ 對 $Y$ 的效果會因為 $Z$ 不同而改變——這時 $Z$ 叫「調節變項」（moderator）。
例：「練習量（$X$）→ 成績（$Y$）」的效果，可能在「動機高」（$Z$ 高）時比較強。
$b_3$ 顯著 $\neq 0$ $\Rightarrow$ $X$ 對 $Y$ 的影響隨 $Z$ 改變（$Z$ 為調節變項）

平減（Centering）後截距

$$X_c = X-\bar{X} \Rightarrow b_0' = \bar{Y}$$
平減＝把每筆資料減掉平均，讓新變項平均=0。好處：讓截距和主效果有意義（在「平均處」的值），且降低交互作用造成的多元共線性。

5.5 相關係數的選擇

兩個連續變項Pearson $r$
兩個次序變項Spearman $\rho$（或 Kendall $\tau$）
一個二元 + 一個連續點雙列相關（Point Biserial）
兩個二元變項Phi 相關（$\phi$）
兩個名義多類別Cramer's $V$
選哪個看資料尺度：連續→Pearson；只有大小順序（排名）→Spearman；含類別變項就用對應的相關。Spearman $\rho$ 唸「rho」、Kendall $\tau$ 唸「tau」、Phi $\phi$ 唸「fai」。

六、ANOVA 自由度完整整理

6.1 單因子受試者間（One-way Between-subjects）

$K$ 組，每組 $n_k$ 人，總 $N=\sum n_k$

來源$df$$MS$$F$
組間（Between）$K-1$$\dfrac{SSB}{K-1}$$\dfrac{MSB}{MSW}$
組內（Within）$N-K$$\dfrac{SSW}{N-K}$
總計$N-1$
ANOVA 的核心想法：「組間差異 vs 組內差異」誰大？
$SSB$ 組間平方和＝各組平均離總平均的差距（組與組間的變異）。
$SSW$ 組內平方和＝每筆資料離自己組平均的差距（純粹個體差異 = 誤差）。
$MS$（均方）= SS / df，把平方和變成「平均變異量」（因為組數越多 SS 自然越大，要除以自由度才公平）。
$F = MSB/MSW$：若各組平均真的不同，組間變異會「大過」純誤差很多 → $F$ 大 → 拒絕「各組平均皆相等」。
$$SSB=\sum_{k}n_k(\bar{X}_k-\bar{X})^2,\quad SSW=\sum_{k}\sum_{i}(X_{ik}-\bar{X}_k)^2,\quad SST=SSB+SSW$$
$SSB$：每組平均減總平均後平方，乘以該組人數 $n_k$（人多的組權重大），全部加總。$SSW$：每筆資料減自己組平均後平方，組內加總，再跨組加總。
最重要的恆等式：$SST = SSB + SSW$（總變異 = 組間變異 + 組內變異）。
$$\eta^2=\frac{SSB}{SST}\qquad\omega^2=\frac{SSB-(K-1)\cdot MSW}{SST+MSW}$$
$\eta^2$（eta squared）＝組間變異佔總變異的比例（解釋 $Y$ 變異的比例），跟迴歸的 $R^2$ 是同個概念。但 $\eta^2$ 會高估，$\omega^2$（omega squared）是修正後較不偏的版本。
df 驗算：$(K-1)+(N-K)=N-1$ ✓

6.2 單因子受試者內（One-way Within-subjects）

$a$ 個水準，$b$ 位受試者，$N=a\times b$

來源$df$
處理（A）$a-1$
受試者（S）$b-1$
誤差（A$\times$S）$(a-1)(b-1)$
總計$ab-1$
「受試者內」＝同一個人接受所有處理（重複量測，例：同樣的人吃 3 種藥，比較三次反應）。
比起「受試者間」，把「個體差異（S）」從誤差裡分離出來，誤差變小 → 統計力變大。
新的誤差項是「A×S」（處理 × 受試者的交互作用），代表「每個人對處理的反應模式不同」的部分。
需球型假設（Sphericity）；違反時用 Greenhouse-Geisser 或 Huynh-Feldt 校正

6.3 二因子受試者間（Two-way Between-subjects）

A 因子 $a$ 水準，B 因子 $b$ 水準，每格 $r$ 人，$N=abr$

來源$df$$F$ 的分母
A 主效果$a-1$$MSE$
B 主效果$b-1$$MSE$
A$\times$B 交互作用$(a-1)(b-1)$$MSE$
誤差（Error）$ab(r-1)$—
總計$abr-1$
兩個獨立變項同時操弄（例：A=性別、B=教學法）。
A 主效果：忽略 B，A 各水準的平均有沒有差。
B 主效果：忽略 A，B 各水準的平均有沒有差。
A×B 交互作用：A 的效果會不會因為 B 的水準而不同（例：教學法的效果在男女身上不一樣）。
受試者間設計三個 $F$ 共用同一個 $MSE$（每格內的純誤差）。
三個 $F$ 的分母都是同一個 $MSE$　　df 驗算：$(a-1)+(b-1)+(a-1)(b-1)+ab(r-1)=abr-1$ ✓

6.4 二因子受試者內（Two-way Within-subjects）

A 因子 $a$ 水準，B 因子 $b$ 水準，$r$ 位受試者（每人接受所有 $ab$ 種條件）

來源$df$誤差項
A$a-1$A$\times$S
B$b-1$B$\times$S
A$\times$B$(a-1)(b-1)$A$\times$B$\times$S
受試者（S）$r-1$—
A$\times$S$(a-1)(r-1)$—
B$\times$S$(b-1)(r-1)$—
A$\times$B$\times$S$(a-1)(b-1)(r-1)$—
總計$abr-1$
同一個人經歷所有 $a\times b$ 種組合。每個效果都有「自己對應的 ×S 誤差項」——因為受試者的反應模式對 A、對 B、對 A×B 可能各不相同。記憶法：檢驗哪個效果，就用「那個效果 × S」當分母。
三個效果各有自己的誤差項，不共用 $MSE$

6.5 混合設計（Mixed Design）

A = 受試者間因子（$a$ 水準），B = 受試者內因子（$b$ 水準），每組 $r$ 人

來源$df$誤差項
A（受試者間）$a-1$$S/A$
$S/A$（受試者間誤差）$a(r-1)$—
B（受試者內）$b-1$$B\times S/A$
A$\times$B$(a-1)(b-1)$$B\times S/A$
$B\times S/A$（受試者內誤差）$a(b-1)(r-1)$—
總計$abr-1$
「混合」＝一個因子受試者間（不同人），一個因子受試者內（同個人重複量）。例：A=男女（不同人），B=前測/中測/後測（同個人三次）。
記號 $S/A$ 唸「S nested in A」＝受試者「巢套」在 A 之下（每個 A 組裡有自己一群人）。受試者間和受試者內的誤差本質不同，所以分配誤差項時不能混用。
混合設計：受試者間（A）和受試者內（B）使用不同誤差項！
A 的誤差 $= S/A$；B 和 A$\times$B 的誤差 $= B\times S/A$

七、效果量（Effect Size）

Cohen's $d$（$t$ 檢定）

$$d = \frac{M_1-M_2}{s_p}\quad\text{小: }0.2\quad\text{中: }0.5\quad\text{大: }0.8$$
「兩組平均差距相當於幾個標準差」。$d=0.5$＝兩組平均差距等於 0.5 個標準差。不受樣本數影響，是「差異的大小」本身。

$\eta^2$（eta squared）

$$\eta^2 = \frac{SS_\text{effect}}{SS_\text{total}}\quad\text{小: }0.01\quad\text{中: }0.06\quad\text{大: }0.14$$
「該效果解釋了 $Y$ 多少比例的變異」。和迴歸的 $R^2$ 同概念，範圍 0~1。

partial $\eta^2$　　　$\omega^2$（較不偏）

$$\text{partial}\;\eta^2 = \frac{SS_\text{effect}}{SS_\text{effect}+SS_\text{error}} \qquad \omega^2 = \frac{SSB-(K-1)\cdot MSW}{SST+MSW}$$
partial $\eta^2$（淨 eta 平方）＝排除其他效果後的解釋比例（分母只看「該效果 + 誤差」，不含其他效果）。多因子設計常報這個。
$\omega^2$（omega squared）＝修正後較不偏的版本，比 $\eta^2$ 更準確估計「母群中的效果大小」。

從 $F$ 值反推 $\eta^2$　　　Cohen's $f$

$$\eta^2 = \frac{F\cdot df_1}{F\cdot df_1+df_2} \qquad f=\sqrt{\frac{\eta^2}{1-\eta^2}}\quad\text{小: }0.10\;\text{中: }0.25\;\text{大: }0.40$$
左式：論文只報 $F$ 和 $df$ 也能反算 $\eta^2$。
Cohen's $f$＝ANOVA 用的效果量，用來計算統計力（power analysis），是 G*Power 軟體的輸入。
$F$ 統計量不是效果量（受 $n$ 影響）！$\eta^2$ 和 $\omega^2$ 才是效果量

八、常用臨界值與快速判斷

8.1 常用 $z$ 臨界值

雙尾 $\alpha=.10$$z=\pm1.645$
雙尾 $\alpha=.05$$z=\pm1.96$
雙尾 $\alpha=.02$$z=\pm2.326$
雙尾 $\alpha=.01$$z=\pm2.576$
單尾 $\alpha=.05$$z=1.645$（右尾）

8.2 統計方法選擇

兩組獨立均值獨立樣本 $t$；無母數：Wilcoxon rank-sum
兩組配對均值配對樣本 $t$；無母數：Wilcoxon signed-rank
三組以上獨立One-way between ANOVA；無母數：Kruskal-Wallis
三組以上重複One-way within ANOVA；無母數：Friedman
兩個類別變項卡方獨立性；$E<5$ 用 Fisher's Exact Test
一個類別分配卡方適合度（$df=k-1$）
一個變異數$\chi^2=(n-1)s^2/\sigma_0^2$
兩個變異數$F=s_1^2/s_2^2$

8.3 Bonferroni 校正

$$\alpha_\text{個別}=\frac{\alpha_\text{家族}}{\text{比較次數}} \qquad \binom{k}{2}=\frac{k(k-1)}{2}\text{（$k$ 組兩兩比較次數）}$$
多重比較問題：做越多次檢定，至少出現一次「假陽性」的機率越高。
Bonferroni 修正法：把每次檢定的 $\alpha$ 變嚴（除以比較次數），讓「家族錯誤率（整體犯錯機率）」維持在 0.05。
$\binom{k}{2}$ 唸「k 取 2」＝從 $k$ 組裡任挑 2 組的組合數，就是「兩兩比較的次數」。
範例：5 組兩兩比較 $\Rightarrow$ $\binom{5}{2}=10$ 次；個別 $\alpha=.05/10=.005$

8.4 常考陷阱提醒

Power $=1-\beta$不是 $1-\alpha$！
$\alpha+\beta\neq 1$兩者不互補
機率密度可以 $>1$面積 $=1$，但高度不限
$r=0\neq$ 無任何關係只是無線性相關，可能有非線性關係
統計顯著 $\neq$ 實質重要需同時看效果量
卡方 $E\geq 5$不是 $E\geq 10$！
$z$ 轉換不改變形狀原始非常態 $\Rightarrow$ z 轉換後仍非常態
降低 $\alpha$ 不提升 Power$\alpha\downarrow\Rightarrow\beta\uparrow\Rightarrow$ Power $\downarrow$
單尾比雙尾更容易顯著單尾把 $\alpha$ 全放一側，不嚴格
