一、描述統計與標準化

1.1 集中趨勢

算術平均數

$$\bar{x} = \frac{\sum_{i=1}^{N} X_i}{N} = \frac{\sum X}{N}$$
中位數 (Md)排序後第 $\frac{N+1}{2}$ 個值；偶數 $N$ 取中間兩值平均
眾數 (Mo)出現次數最多的值（可有多個）
偏態與三者正偏（右偏）：$\text{Mo} < \text{Md} < \bar{X}$　　負偏（左偏）：$\bar{X} < \text{Md} < \text{Mo}$

1.2 離散趨勢

母群變異數（定義式）

$$\sigma^2 = \frac{\sum(X_i - \mu)^2}{N}$$

母群變異數（計算式）

$$\sigma^2 = \frac{\sum X_i^2}{N} - \mu^2 = \frac{\displaystyle\sum X^2 - \frac{(\sum X)^2}{N}}{N}$$

樣本變異數（不偏，定義式）

$$s^2 = \frac{\sum(X_i - \bar{x})^2}{N-1}$$

樣本變異數（計算式）— 除 $N-1$

$$s^2 = \frac{\displaystyle\sum X^2 - \frac{(\sum X)^2}{N}}{N-1}$$

標準差　　　變異係數

$$\sigma = \sqrt{\sigma^2},\quad s = \sqrt{s^2} \qquad CV = \frac{SD}{Mean} \times 100\%$$
全距$R = X_{\max} - X_{\min}$
四分位距$\text{IQR} = Q_3 - Q_1$
線性轉換：$\text{Var}(a+bX) = b^2\cdot\text{Var}(X)$；$\text{SD}(a+bX) = |b|\cdot\text{SD}(X)$；加常數 $a$ 不影響 SD

1.3 z 分數（標準化）

z 分數　　　反推原始分數

$$z = \frac{X - \mu}{\sigma} \qquad X = \mu + z\cdot\sigma$$ 標準化後：$\mu_z = 0$，$\sigma_z = 1$（分配形狀不變！）
z 轉換不改變分配形狀！原始非常態 → 轉換後仍非常態

1.4 偏態與峰度

偏態（Skewness）—— 三次方矩

$$g_1 = \frac{\dfrac{1}{N}\sum(X_i - \bar{x})^3}{s^3}$$

峰度（Kurtosis）—— 四次方矩（尾端厚度）

$$g_2 = \frac{\dfrac{1}{N}\sum(X_i - \bar{x})^4}{s^4} - 3 \quad\text{（超額峰度；常態分配 }g_2=0\text{）}$$

二、機率分配

2.1 常用分配摘要

常態 $N(\mu,\sigma^2)$$\mu\pm1\sigma=68.26\%$；$\mu\pm2\sigma=95.44\%$；$\mu\pm3\sigma=99.74\%$
標準常態 $Z$$\mu=0$，$\sigma=1$；$z_{0.025}=1.96$，$z_{0.005}=2.576$
$t(df)$$df\to\infty$ 趨近 $Z$；$\text{Var}=\dfrac{df}{df-2}>1$，尾端比 $Z$ 厚
$\chi^2(df)$$\chi^2=\sum Z_i^2$（$df$ 個獨立 $Z^2$ 之和）；右偏；$df\to\infty$ 趨近常態
$F(df_1,df_2)$$F=\dfrac{\chi^2(df_1)/df_1}{\chi^2(df_2)/df_2}$；右偏；$F=t^2$（兩組）
二項 $B(n,p)$$E(X)=np$；$\text{Var}=np(1-p)$；$n$ 大時趨近常態
波松 $\text{Pois}(\lambda)$$E(X)=\text{Var}(X)=\lambda$；單位時間事件次數
超幾何不放回抽樣；有限母群；每次 $p$ 改變
伯努利 $B(p)$$n=1$ 的二項；單次試驗（0或1）
$F=t^2$（兩組）；機率密度（PDF值）可以 $>1$（面積$=1$，高度不限）

2.2 抽樣分配與標準誤

標準誤（SE）

$$SE_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$$

比例的 SE　　　兩比例差的 SE

$$SE_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}} \qquad SE_{\hat{p}_1-\hat{p}_2} = \sqrt{\frac{p_1(1-p_1)}{n_1} + \frac{p_2(1-p_2)}{n_2}}$$

三、信賴區間與樣本數估計

均值 CI（$\sigma$ 已知）　　均值 CI（$\sigma$ 未知）

$$\bar{x} \pm z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}} \qquad \bar{x} \pm t_{\alpha/2,\,n-1}\cdot\frac{s}{\sqrt{n}}$$

比例 CI

$$\hat{p} \pm z_{\alpha/2}\cdot\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

樣本數估計（一般式）　　樣本數估計（保守，$p=0.5$）

$$n \geq \frac{z_{\alpha/2}^2\cdot p(1-p)}{E^2} \qquad n \geq \frac{z_{\alpha/2}^2\cdot 0.25}{E^2} = \left(\frac{z_{\alpha/2}}{2E}\right)^2$$

範例：95% 信心（$z=1.96$），誤差半寬 $E=0.02$

$$n \geq \left(\frac{1.96}{2\times 0.02}\right)^2 = 49^2 = 2401 \approx 2500$$
$E$ = 誤差「半寬」；若題目說「上下誤差總範圍 $0.04$」則 $E = 0.02$

四、假設檢定

4.1 基本概念

Type I error ($\alpha$)H$_0$ 為真卻拒絕 H$_0$（偽陽性）= 顯著水準
Type II error ($\beta$)H$_1$ 為真卻保留 H$_0$（偽陰性）
Power（統計力）$1-\beta = P(\text{拒絕 H}_0 \mid \text{H}_1\text{ 為真})$；通常要求 $\geq 0.80$
$p$ 值H$_0$ 為真時，觀察到此結果或更極端的機率
決策$p < \alpha \Rightarrow$ 拒絕 H$_0$；$p \geq \alpha \Rightarrow$ 保留 H$_0$（非接受！）
$\alpha + \beta \neq 1$！　Power $= 1-\beta$（不是 $1-\alpha$）
$\alpha\uparrow\Rightarrow$ Power $\uparrow$；$n\uparrow\Rightarrow$ Power $\uparrow$；效果量 $\uparrow\Rightarrow$ Power $\uparrow$

4.2 各種 $t$ 檢定

單樣本 $t$

$$t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}},\quad df = n-1$$

獨立樣本 $t$

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_p^2\!\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}},\quad df = n_1+n_2-2$$

調和變異數（Pooled Variance）

$$s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1+n_2-2}$$

配對樣本 $t$　（$D_i = X_{1i} - X_{2i}$）

$$t = \frac{\bar{D}}{s_D/\sqrt{n}},\quad df = n-1$$

$t$ 與 $F$ 的關係

$$F(1,\;df) = t^2(df)\quad\text{（兩組時）}$$

4.3 卡方檢定

卡方統計量　　　期望值（列聯表）

$$\chi^2 = \sum\frac{(O-E)^2}{E} \qquad E_{ij} = \frac{\text{列和}_i \times \text{欄和}_j}{N}$$

適合度：$df = k-1$（$k$=類別數）　　獨立性：$df = (r-1)(c-1)$

單樣本變異數

$$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2},\quad df = n-1$$
期望值要求 $E \geq 5$（不是10！）；$E < 5$ 時考慮 Fisher's Exact Test

五、相關與迴歸

5.1 Pearson 相關

定義式

$$r = \frac{\text{Cov}(X,Y)}{\sigma_X\cdot\sigma_Y} = \frac{\sum(X_i-\bar{x})(Y_i-\bar{y})}{\sqrt{\sum(X_i-\bar{x})^2\cdot\sum(Y_i-\bar{y})^2}}$$

計算式

$$r = \frac{\displaystyle\sum X_i Y_i - \frac{(\sum X_i)(\sum Y_i)}{N}}{\sqrt{\left[\displaystyle\sum X_i^2 - \frac{(\sum X_i)^2}{N}\right]\!\left[\displaystyle\sum Y_i^2 - \frac{(\sum Y_i)^2}{N}\right]}}$$

共變數　　　$r$ 的 $t$ 檢定

$$\text{Cov}(X,Y)=r\cdot\sigma_X\cdot\sigma_Y \qquad t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}},\quad df=n-2$$

決定係數

$$R^2 = r^2\quad\text{（$X$ 能解釋 $Y$ 的變異比例）}$$
$r=0$ 只代表無「線性」相關；可能有非線性關係！
$R^2$ 對稱：$X$ 預測 $Y$ 和 $Y$ 預測 $X$ 的 $R^2$ 完全相同

5.2 簡單線性迴歸

迴歸方程式

$$\hat{Y} = b_0 + b_1 X$$

斜率（定義式 / 計算式）

$$b_1 = \frac{\text{Cov}(X,Y)}{\text{Var}(X)} = r\cdot\frac{s_Y}{s_X} = \frac{\displaystyle\sum X_i Y_i - \frac{(\sum X_i)(\sum Y_i)}{N}}{\displaystyle\sum X_i^2 - \frac{(\sum X_i)^2}{N}}$$

截距　　　標準化迴歸係數

$$b_0 = \bar{Y} - b_1\bar{X}\quad\text{（迴歸線必過 $(\bar{X},\bar{Y})$）} \qquad \beta = r\quad\text{（截距}=0\text{）}$$

估計標準誤（SEE）

$$SEE = s_Y\sqrt{1-R^2} = \sqrt{\frac{\sum(Y_i-\hat{Y}_i)^2}{N-2}}$$

95% 預測區間　　　整體 $F$ 檢定

$$\hat{Y}\pm 1.96\cdot SEE \qquad F=\frac{R^2/p}{(1-R^2)/(N-p-1)},\quad df_1=p,\;df_2=N-p-1$$
$X$ 和 $Y$ 互換後斜率不同（除非 $s_X=s_Y$），但 $R^2$ 相同

5.3 多元迴歸

多元迴歸方程式　　　調整後 $R^2$

$$\hat{Y} = b_0 + b_1X_1 + \cdots + b_pX_p \qquad R^2_{\text{adj}} = 1-(1-R^2)\frac{N-1}{N-p-1}$$

整體 $F$ 檢定

$$F(p,\;N-p-1)=\frac{R^2/p}{(1-R^2)/(N-p-1)}$$

5.4 虛擬變項與調節迴歸

$k$ 類別 $\Rightarrow$ $k-1$ 個虛擬變項（以1組為參照組）
截距 $=$ 參照組均值；各組係數 $=$ 該組均值 $-$ 參照組均值

調節迴歸（含交互作用）

$$\hat{Y} = b_0 + b_1X + b_2Z + b_3XZ$$ $b_3$ 顯著 $\neq 0$ $\Rightarrow$ $X$ 對 $Y$ 的影響隨 $Z$ 改變（$Z$ 為調節變項）

平減（Centering）後截距

$$X_c = X-\bar{X} \Rightarrow b_0' = \bar{Y}$$

5.5 相關係數的選擇

兩個連續變項Pearson $r$
兩個次序變項Spearman $\rho$（或 Kendall $\tau$）
一個二元 + 一個連續點雙列相關（Point Biserial）
兩個二元變項Phi 相關（$\phi$）
兩個名義多類別Cramer's $V$

六、ANOVA 自由度完整整理

6.1 單因子受試者間（One-way Between-subjects）

$J$ 組，每組 $n_j$ 人，總 $N=\sum n_j$

來源$df$$MS$$F$
組間（Between）$J-1$$\dfrac{SSB}{J-1}$$\dfrac{MSB}{MSW}$
組內（Within）$N-J$$\dfrac{SSW}{N-J}$
總計$N-1$
$$SSB=\sum_{j}n_j(\bar{X}_j-\bar{X})^2,\quad SSW=\sum_{j}\sum_{i}(X_{ij}-\bar{X}_j)^2,\quad SST=SSB+SSW$$ $$\eta^2=\frac{SSB}{SST}\qquad\omega^2=\frac{SSB-(J-1)\cdot MSW}{SST+MSW}$$
df 驗算：$(J-1)+(N-J)=N-1$ ✓

6.2 單因子受試者內（One-way Within-subjects）

$a$ 個水準，$n$ 位受試者，$N=a\times n$

來源$df$
處理（A）$a-1$
受試者（S）$n-1$
誤差（A$\times$S）$(a-1)(n-1)$
總計$an-1$
需球型假設（Sphericity）；違反時用 Greenhouse-Geisser 或 Huynh-Feldt 校正

6.3 二因子受試者間（Two-way Between-subjects）

A 因子 $a$ 水準，B 因子 $b$ 水準，每格 $n$ 人，$N=abn$

來源$df$$F$ 的分母
A 主效果$a-1$$MSE$
B 主效果$b-1$$MSE$
A$\times$B 交互作用$(a-1)(b-1)$$MSE$
誤差（Error）$ab(n-1)$—
總計$abn-1$
三個 $F$ 的分母都是同一個 $MSE$　　df 驗算：$(a-1)+(b-1)+(a-1)(b-1)+ab(n-1)=abn-1$ ✓

6.4 二因子受試者內（Two-way Within-subjects）

A 因子 $a$ 水準，B 因子 $b$ 水準，$n$ 位受試者（每人接受所有 $ab$ 種條件）

來源$df$誤差項
A$a-1$A$\times$S
B$b-1$B$\times$S
A$\times$B$(a-1)(b-1)$A$\times$B$\times$S
受試者（S）$n-1$—
A$\times$S$(a-1)(n-1)$—
B$\times$S$(b-1)(n-1)$—
A$\times$B$\times$S$(a-1)(b-1)(n-1)$—
總計$abn-1$
三個效果各有自己的誤差項，不共用 $MSE$

6.5 混合設計（Mixed Design）

A = 受試者間因子（$a$ 水準），B = 受試者內因子（$b$ 水準），每組 $n$ 人

來源$df$誤差項
A（受試者間）$a-1$$S/A$
$S/A$（受試者間誤差）$a(n-1)$—
B（受試者內）$b-1$$B\times S/A$
A$\times$B$(a-1)(b-1)$$B\times S/A$
$B\times S/A$（受試者內誤差）$a(b-1)(n-1)$—
總計$abn-1$
混合設計：受試者間（A）和受試者內（B）使用不同誤差項！
A 的誤差 $= S/A$；B 和 A$\times$B 的誤差 $= B\times S/A$

七、效果量（Effect Size）

Cohen's $d$（$t$ 檢定）

$$d = \frac{M_1-M_2}{s_p}\quad\text{小: }0.2\quad\text{中: }0.5\quad\text{大: }0.8$$

$\eta^2$（eta squared）

$$\eta^2 = \frac{SS_\text{effect}}{SS_\text{total}}\quad\text{小: }0.01\quad\text{中: }0.06\quad\text{大: }0.14$$

partial $\eta^2$　　　$\omega^2$（較不偏）

$$\text{partial}\;\eta^2 = \frac{SS_\text{effect}}{SS_\text{effect}+SS_\text{error}} \qquad \omega^2 = \frac{SSB-(J-1)\cdot MSW}{SST+MSW}$$

從 $F$ 值反推 $\eta^2$　　　Cohen's $f$

$$\eta^2 = \frac{F\cdot df_1}{F\cdot df_1+df_2} \qquad f=\sqrt{\frac{\eta^2}{1-\eta^2}}\quad\text{小: }0.10\;\text{中: }0.25\;\text{大: }0.40$$
$F$ 統計量不是效果量（受 $n$ 影響）！$\eta^2$ 和 $\omega^2$ 才是效果量

八、常用臨界值與快速判斷

8.1 常用 $z$ 臨界值

雙尾 $\alpha=.10$$z=\pm1.645$
雙尾 $\alpha=.05$$z=\pm1.96$
雙尾 $\alpha=.02$$z=\pm2.326$
雙尾 $\alpha=.01$$z=\pm2.576$
單尾 $\alpha=.05$$z=1.645$（右尾）

8.2 統計方法選擇

兩組獨立均值獨立樣本 $t$；無母數：Wilcoxon rank-sum
兩組配對均值配對樣本 $t$；無母數：Wilcoxon signed-rank
三組以上獨立One-way between ANOVA；無母數：Kruskal-Wallis
三組以上重複One-way within ANOVA；無母數：Friedman
兩個類別變項卡方獨立性；$E<5$ 用 Fisher's Exact Test
一個類別分配卡方適合度（$df=k-1$）
一個變異數$\chi^2=(n-1)s^2/\sigma_0^2$
兩個變異數$F=s_1^2/s_2^2$

8.3 Bonferroni 校正

$$\alpha_\text{個別}=\frac{\alpha_\text{家族}}{\text{比較次數}} \qquad \binom{k}{2}=\frac{k(k-1)}{2}\text{（$k$ 組兩兩比較次數）}$$ 範例：5 組兩兩比較 $\Rightarrow$ $\binom{5}{2}=10$ 次；個別 $\alpha=.05/10=.005$

8.4 常考陷阱提醒

Power $=1-\beta$不是 $1-\alpha$！
$\alpha+\beta\neq 1$兩者不互補
機率密度可以 $>1$面積 $=1$，但高度不限
$r=0\neq$ 無任何關係只是無線性相關，可能有非線性關係
統計顯著 $\neq$ 實質重要需同時看效果量
卡方 $E\geq 5$不是 $E\geq 10$！
$z$ 轉換不改變形狀原始非常態 $\Rightarrow$ z 轉換後仍非常態
降低 $\alpha$ 不提升 Power$\alpha\downarrow\Rightarrow\beta\uparrow\Rightarrow$ Power $\downarrow$
單尾比雙尾更容易顯著單尾把 $\alpha$ 全放一側，不嚴格
